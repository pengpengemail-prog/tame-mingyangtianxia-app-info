# TAME 名扬天下 GitHub Pages 站点

这个目录是给 `Support URL` 和 `Privacy Policy URL` 准备的静态站点骨架。

## 包含内容
- `index.html`：总览页
- `support.html`：支持说明页
- `privacy.html`：隐私政策页
- `styles.css`：统一样式

## 发布前需要替换
当前版本默认使用 GitHub Issues 作为公开支持入口，不再依赖私人邮箱公开展示。

## GitHub Pages 发布建议
1. 新建一个公开仓库，例如 `tame-mingyangtianxia-app-info`.
2. 把本目录下的所有文件上传到仓库根目录。
3. 在 GitHub 仓库设置中开启 Pages。
4. 如果 Pages 根目录就是仓库根目录：
   - `index.html` 可作为主页
   - `support.html` 可填写为 Support URL
   - `privacy.html` 可填写为 Privacy Policy URL

## 推荐 URL 结构
- `https://pengpengemail-prog.github.io/tame-mingyangtianxia-app-info/support.html`
- `https://pengpengemail-prog.github.io/tame-mingyangtianxia-app-info/privacy.html`
